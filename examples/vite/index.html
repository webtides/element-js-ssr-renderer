element-js SSR renderer — Vite example

Every custom element below is authored as plain HTML in this index.html. The elementSSR Vite plugin pre-renders each one at build time via the stable transformIndexHtml hook — shadow components as Declarative Shadow DOM, light-DOM components in place — so the built dist/index.html is fully rendered with no server.

To see it work: run npm run build and look at dist/index.html (or view source in preview/dev) — the components are already fully rendered, including <template shadowrootmode="open"> for the shadow ones, before any client JS. With JS on, the counter's buttons work: that's hydration, not a re-render.
